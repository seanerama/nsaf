# NSAF Study Preferences

Preferences for generating study plan / textbook topic ideas (consumed by the StudyWS pipeline).

## Subject Domains
- networking fundamentals, routing, switching
- network automation and Infrastructure-as-Code (Ansible, Terraform, Python netdev)
- cloud platforms (AWS, Azure, GCP) — services, networking, identity
- container orchestration (Kubernetes, Docker, service mesh)
- security and vulnerability management (offensive and defensive)
- observability, monitoring, and SRE practices
- linux systems administration and shell tooling
- programming languages and tooling (Python, Go, JavaScript runtimes)
- data engineering pipelines and warehousing
- machine learning operations and production AI systems
- API design, REST/GraphQL, and integration patterns
- databases — relational, key-value, time-series, vector
- certification exam tracks (Cisco, AWS, Kubernetes, security)

## Levels
- Min: intermediate
- Max: advanced

## Source Material Tendency
- prefer topics with authoritative public source documents (RFCs, vendor exam blueprints, official docs, well-maintained whitepapers)
- include open-ended topics without source URLs occasionally — the study material can be derived
- when an exam blueprint exists, prefer linking to it directly

## Chapter Range
- Min: 8
- Max: 20

## Exclusions
- consumer-grade tech reviews and product comparisons
- topics too narrow to fill 8+ chapters of substantive material
- duplicate exam-prep tracks already covered in projects/sws-*
- topics that age out within 6 months (release-specific feature posts)
- pure history or trivia disconnected from working practice

## Tone
- technical, precise, exam-prep oriented
- include why this matters for a working engineer or operator
- favor depth over breadth

## Model Profile
balanced

20
